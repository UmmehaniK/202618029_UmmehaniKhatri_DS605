### Objective

To perform data preprocessing using Scikit-learn and compare classification models on the Hotel Booking Demand dataset.

### Dataset

Hotel Booking Demand (`hotel_bookings.csv`)

### Preprocessing

* Missing-value handling using KNN Imputer and Simple Imputer
* Categorical encoding using OneHotEncoder
* StandardScaler
* MinMaxScaler
* Removal of data leakage columns
* Train-test split with 80:20 ratio

### Models

* Logistic Regression
* Decision Tree Classifier

### Evaluation

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

### Conclusion

The four model-preprocessing combinations were compared to identify the best overall performance and examine the effect of different scaling methods.
